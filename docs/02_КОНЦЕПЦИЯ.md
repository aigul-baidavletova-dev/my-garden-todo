# 02. Концепция и дизайн

## Центральная метафора: 3D-сад, в котором дела вырастают в деревья

Весь экран занимает трёхмерный сад. Каждая задача — растение. Новая задача —
**росток**. Выполнила её — на этом месте **вырастает дерево**. Сад можно вращать
мышью или пальцем и приближать колесом. Панель задач лежит поверх сада, её можно свернуть.

У каждой задачи **своё уникальное дерево**: дуб, ель, яблоня, сакура или берёза,
своей высоты, с наклоном и своей формой кроны. После перезагрузки страницы
сад выглядит точно так же.

Небо и свет зависят от **времени суток**: утро, вечер (закат, светлячки) или ночь
(звёзды, лунный свет). По умолчанию — по часам, но можно выбрать вручную.

**Почему это сильная идея для ФП-лабы:**
- Дерево «случайное», но `Math.random` не используется: форма вычисляется **чистой функцией**
  `plantFor(id)` из «зерна» — хеша от id задачи. Тот же id → то же дерево.
- Место в саду — тоже чистая функция: `gardenSlot(index)` раскладывает растения
  по спирали «золотого угла», как семечки в подсолнухе.
- Время суток — чистое правило `phaseOfHour(hour)`. Час читает оболочка
  (`new Date()` нечистый), а ядро получает его аргументом. Поэтому «ночь» легко
  проверить тестом, даже если запускать его днём.
- three.js (библиотека 3D) изменяемая по своей природе, поэтому живёт только в оболочке
  и получает от ядра данные: «вот дерево, вот его место, вот цвета неба».

## Обязательный функционал (из задания)

| Требование | Как выглядит в интерфейсе |
|---|---|
| Добавлять задачи | Поле «Что посадим?» + кнопка «Посадить»; `Enter` добавляет; пустую строку и одни пробелы добавить нельзя |
| Отмечать выполненные | Клик по чекбоксу-листику или названию; в саду росток вырастает в дерево |
| Удалять | Кнопка × на карточке; растение уходит под землю; тост «Задача удалена · Вернуть» |
| Фильтровать | Три переключателя: **Все / Растут / Выросли** со счётчиками |

## Дополнения

**«Аккуратно»**
- [x] Счётчики в фильтрах через `reduce`
- [x] Пустые состояния: свой текст для каждого фильтра («Грядка пуста. Что посадим?»)
- [x] Сохранение в `localStorage`: после перезагрузки всё на месте, испорченные данные не ломают приложение
- [x] Доступность: `<label>`, фокус с клавиатуры, `aria-pressed`, `aria-live` для итогов

**«С характером»**
- [x] 3D-сад на весь экран: низкополигональные деревья, тени, трава, цветы, камни
- [x] Анимации: росток появляется, дерево вырастает, растение уходит под землю, крона качается
- [x] Утро, вечер и ночь: по часам или вручную
- [x] Наведение на дерево показывает, какая это задача и какая порода
- [x] `prefers-reduced-motion`: без движения для тех, кому оно мешает

**«Инженерно»**
- [x] Свой мини-фреймворк тестов и зелёные тесты для всех чистых функций
- [x] `deepFreeze` состояния в режиме разработки (ловит случайные мутации)
- [x] Сортировка через фабрику компараторов, поиск как композиция предикатов
- [x] three.js подгружается отдельно: если 3D недоступно, список задач всё равно работает

## Визуальный стиль

- **Сад:** low-poly (гранёные формы), мягкие тени. Цвета неба, света и земли
  меняются плавно при смене времени суток. Вечером над садом летают светлячки,
  ночью на небе звёзды.
- **Панель:** полупрозрачное «стекло» поверх сада (`backdrop-filter: blur`).
  Три набора цветов: светлая утром, сливовая на закате, тёмно-синяя ночью.
  На телефоне панель внизу экрана, сад сверху.
- **Карточки:** невыполненная задача — пунктирная рамка и чекбокс в форме листика.
  Выполненная — зелёный фон.
- **Шрифты:** `Lora` (с засечками, курсив для подписей) и `JetBrains Mono` для дат.

## UX-правила, которые нельзя нарушать ради креатива

1. Основные действия видны сразу, без поиска.
2. Всё доступно с клавиатуры: `Tab`, `Enter`, `Space`.
3. Контраст текста не ниже 4.5:1, даже когда под полупрозрачной панелью яркое небо.
4. Анимации не мешают продолжать работу.
5. Удаление можно отменить тостом «Вернуть», поэтому диалог «вы уверены?» не нужен.
6. Вёрстка работает на ширине 360 px (телефон).
7. Сад — декорация: холст скрыт от скринридера (`aria-hidden`), те же задачи
   он прочитает в списке. Вслух объявляется только итог: «Выросло 3 дерева · 1 росток ждёт».
8. Если WebGL не работает, приложение не ломается: остаётся список и сообщение.
